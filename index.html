Lishui Fan

Ph.D. Student, College of Computer Science and Technology, Zhejiang University

flscode@zju.edu.cn

Hangzhou, China

I am a third-year Ph.D. student at the College of Computer Science and Technology, Zhejiang University, advised by Zhongxin Liu and Shanping Li. My research focuses on large language models for code generation, with broader interests in large language models, code-change understanding, and coding agents. I was fortunate to intern at Alibaba Future Life Lab and ByteDance Douyin AI4SE. Over the past two years, I have published or had accepted four first-author CCF-A papers in software engineering and related areas, including work in ACM TOSEM, ASE, and ACL.

selected publications

  1. ReCode: Reinforcing Code Generation with Reasoning-Process Rewards
    Lishui Fan, Yu Zhang, Mouxiang Chen, and 1 more author
    In Proceedings of the 64th Annual Meeting of the Association for Computational Linguistics, 2026
    Accepted to ACL 2026 Main Conference
    Abs DOI

    This work proposes ReCode, a reasoning-reinforced code generation framework that trains reasoning-process reward models and gates process rewards with strict execution outcomes.

  2. ZeroCoder: Can LLMs Improve Code Generation Without Ground-Truth Supervision?
    Lishui Fan, Mouxiang Chen, Tingwei Zhu, and 4 more authors
    arXiv preprint, 2026
    Abs DOI

    This work studies whether LLMs can improve code generation without ground-truth supervision through label-free co-evolution of code and test generation.

  3. Balancing Latency and Accuracy of Code Completion via Local-Cloud Model Cascading
    Hanzhen Lu, Lishui Fan, Jiachi Chen, and 3 more authors
    In Proceedings of the 34th ACM International Conference on the Foundations of Software Engineering, 2026
    Abs DOI

    This collaborative work studies local-cloud model cascading for low-latency and high-accuracy code completion.

  4. Exploring the Capabilities of LLMs for Code-Change-Related Tasks
    Lishui Fan, Jiakun Liu, Zhongxin Liu, and 3 more authors
    ACM Transactions on Software Engineering and Methodology, 2025
    Abs DOI

    This work studies how large language models perform on code-change-related tasks, including code review generation, commit message generation, and just-in-time comment update.

  5. FGit: Fault-Guided Fine-Tuning for Code Generation
    Lishui Fan, Zhongxin Liu, Haoye Wang, and 3 more authors
    In Proceedings of the 40th IEEE/ACM International Conference on Automated Software Engineering, 2025
    Abs DOI

    This work introduces fault-guided fine-tuning for code generation by emphasizing error-sensitive code segments during training.

  6. SEK: Self-Explained Keywords Empower Large Language Models for Code Generation
    Lishui Fan, Mouxiang Chen, and Zhongxin Liu
    In Findings of the Association for Computational Linguistics: ACL 2025, 2025
    Abs DOI

    This work proposes self-explained keywords to help LLMs better understand low-frequency, problem-specific terms in code generation prompts.
