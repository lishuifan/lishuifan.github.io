This project line focuses on making code LLM training more sensitive to the real reasons why generated programs fail. FGit emphasizes error-sensitive segments during fine-tuning, while Posterior-GRPO studies process rewards for reasoning in code generation and conditions process feedback on successful task outcomes.

The broader goal is to move beyond outcome-only supervision and design training signals that better align model behavior with correct, robust code generation.
